# Information Security Policy

Document ID: SEC-001
Effective: January 1, 2026

## Encryption

All customer data is encrypted at rest using AES-256 and in transit using TLS 1.2 or higher.

## Data retention

After a contract ends, customer data is kept for 90 days to allow export, and is then permanently
deleted from production systems and backups.

## Security incident notification

If a security incident affects a customer's data, Northstar Cloud notifies the customer's
designated security contact within 72 hours of confirming the incident. Individual contracts may
specify a shorter notification period.

## Access control

Production access requires SSO with hardware-key MFA and is reviewed quarterly by the Security Lead.
